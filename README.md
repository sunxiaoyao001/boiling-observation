线上地址：<https://sunxiaoyao001.github.io/boiling-observation/>

## 数据说明

页面中的温度序列、沸点、能量账等数字是**课堂演示用的示例数据集**，用于展示报告结构与可视化方式。正式提交前请替换为自己实测的数据：

- 加热曲线数据：`assets/js/main.js` 第 79 行的 `T` 数组（每个元素是一次计温的温度 ℃），配套改 `STEP`（计温间隔，秒）
- 阶段划分：同文件 `PHASES` 数组的 `until`（秒）与阶段说明文案
- 沸点、起响温度、波动幅度：初步效果区的四张数据卡
- 能量账：原理区 `.panel-dark` 内的 `Q = cmΔT` 与 `Q = Lm`

曲线折线与数据点由 `T` 自动重绘（HTML 里保留了一份静态路径，仅在禁用 JS 时兜底）。横轴刻度数字仍是静态文本，改了 `STEP` 需同步改 `index.html` 里的 `<text>` 刻度。

## 技术

纯静态站点，无框架、无构建步骤、无 npm 依赖。

- `index.html` —— 结构与全部文案
- `assets/css/style.css` —— 设计令牌与全部样式，含 `@media print` 打印样式
- `assets/js/main.js` —— 章节高亮、滚动揭示、曲线时间轴
- `assets/fonts/` —— 自托管 Sora（标题）与 IBM Plex Mono（数据）

字体只自托管拉丁子集，中文走系统字体栈（PingFang SC / 微软雅黑 / Noto Sans SC），以控制体积。
